Variables del Proyecto

Relación entre las variables principales del proceso de investigación.

Variable Independiente

Aplicación móvil con geolocalización.


Corresponde a la herramienta tecnológica diseñada para registrar, visualizar y gestionar incidencias urbanas mediante el uso de georreferenciación.

Variable Dependiente

Optimización del proceso de reporte y gestión de incidencias urbanas.


Hace referencia a la mejora en eficiencia, organización, seguimiento y participación ciudadana dentro del sistema propuesto.

Dimensiones e Indicadores

Dimensión Indicador Descripción
Usabilidad Facilidad de uso Nivel de interacción del usuario con la aplicación móvil.
Funcionalidad Registro de incidencias Capacidad del sistema para registrar correctamente reportes ciudadanos.
Geolocalización Precisión Exactitud de la ubicación geográfica de las incidencias reportadas.
Eficiencia Tiempo de respuesta Tiempo requerido para atender incidencias urbanas.
Organización Seguimiento Capacidad del sistema para realizar trazabilidad de reportes.
Participación ciudadana Nivel de uso Cantidad de usuarios y reportes generados mediante la aplicación.
